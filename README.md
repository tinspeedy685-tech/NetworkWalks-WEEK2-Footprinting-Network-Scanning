This repository documents my second-week practical activities during my cybersecurity internship at Networkwalks.

Tools used:

- WhatWeb
- Nslookup
- cURL

- DNSRecon

### W2-PM5 – Zenmap-Based Network Scanning

Activities performed:
- Identified local network configuration using `ipconfig`.
- Identified the VMware VMnet1 subnet.
- Performed a Ping Scan using Zenmap.
- Identified responsive hosts on the selected subnet.
- Reviewed the scan output and host information.
